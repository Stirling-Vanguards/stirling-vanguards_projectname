Dark is the brand

The near-black space canvas and planetary photography are the identity. A light variant exists only for accessibility and print — brand surfaces stay dark in both.

Token-driven, zero build

Science-safe by construction

01 / PRINCIPLES

Four rules the system cannot break

These are not stylistic preferences. They encode the project's data contract and its "no blended score" scientific rule. A component that violates one of these is a bug, not a variation.

① Never blend dimensions

Features may only be aggregated within one dimension. The system ships no "overall similarity" component, no average, no composite hero number, no star rating.

② 0.00 ≠ not scored

0.00 is a valid, measured "no match" and must be drawn. A missing optional dimension is omitted and shown as not scored with a dashed/italic treatment — never as zero.

③ Colour is never alone

Dimensions carry a hue + 2-letter code + swatch + label. Bodies carry a hue + solid/dashed ring + monogram. Confidence carries a hue + 3-bar meter + text label.

④ Brand glows, instruments don't

Glow, starfields and outline type belong to the cinematic shell. Data surfaces use flat backgrounds and hairline borders so numbers stay readable against a live basemap.

Live rule flagcomponent
Dimensions are compared one at a time. This product has no overall similarity score.

04 / SPACE & FORM

Space, radius, elevation, motion

A 4px base grid. Radius increases with surface size: 6px controls, 10px panels, 14px cards, 20px image tiles, pill chips. Elevation is subtle on dark — borders do most of the separation.

Elevation

--shadow-1 panels → --shadow-4 modals. On dark, pair every shadow with a 1px hairline border; a shadow alone disappears.

Motion

Data interactions --dur-2 160ms; brand reveals --dur-4 480ms. Animate opacity and transform only. prefers-reduced-motion zeroes every duration.

13 / ACCESSIBILITY & VOICE

Accessibility and content rules

Try the theme and high-contrast switches in the top bar, and Tab through this page. Every interactive element has a visible 2px focus ring with 2px offset.

RequirementImplementation
Contrast--fg-primary on --bg-panel ≈ 15:1; --fg-muted ≈ 6:1. Text-bearing CTA uses --gradient-cta-solid for ≥ 4.5:1 white text.
Colour independenceDimension = hue + code + swatch + label. Body = hue + solid/dashed ring + monogram. Confidence = hue + 3 bars + text.
Focus:focus-visible → 2px solid var(--focus), 2px offset, on links, buttons, selects, inputs and the map canvas.
Touch--touch-min: 44px on coarse pointers. The audited 36px controls are bumped to 40px minimum on desktop.
Screen readersaria-pressed on segments, aria-sort on ranked column, aria-live on status and card slot, role="img" + title/desc on radar.
Motionprefers-reduced-motion zeroes all four duration tokens and disables shimmer/fade animations.
Zoom & reflowrem-based type, grid reflows at 1200 / 900 / 600px, table scrolls horizontally rather than clipping.

Token governanceone source, one mirror

src/design/tokens.json is the machine-readable source of truth; src/styles/tokens.css is its runtime mirror; src/design/tokens.js bridges tokens into MapLibre. A value change must update the JSON and the CSS together. Component files may only reference semantic tokens — a raw hex outside tokens.css is a review failure. Dimension labels always come from meta.json, so a contract decision never requires a design-system edit.
