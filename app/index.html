How the atlas works

01 / DIMENSIONS

One dimension at a time

Terrain, thermal, geology and subsurface are separate properties. Rank or map sites by a single dimension — features are never blended into one overall similarity score.

02 / SCORES

A zero is not a gap

0.00 means a measured "no match". An unmeasured optional dimension is not scored and is omitted from the record — it is never silently turned into zero.

03 / CONFIDENCE

Weakest link, stated

Confidence is derived from measurement inputs, source verification, spatial support and pixel validity. The lowest dimension sets the record's confidence; nothing is averaged.

04 / PROVENANCE

Every number has a source

Each run is published only after a quality gate. Run ID, generation time, dataset hashes, schema version and quality results ship as sidecars next to the site records.

Dimensions are compared one at a time. This product has no overall similarity score.
